# OmniVision
This mod adds a new functional 360° surveillance camera to the game, as well as the ability to display any cameras on in-game TVs.

**⚠️WARNING⚠️ This version of OmniVision is designed to function with VotV a0.9.0j. Using older or newer versions of the game may cause errors!**  

If you have any suggestions or encounter a bug, you can submit it as an issue on my [GitHub repository](https://github.com/Acitulen/OmniVision).

# **Configs**:
Configs can be accessed in the game settings under the **Mod configs** category or by pressing **Ctrl+Shift+C**.

- **Lidar/Angle** - Sets the scanning angle of the lidar (in degrees)  
  **Default:** `40`

- **Lidar/PointsPerTick** - Sets the number of scan points generated per tick.   
  **Default:** `100`

- **Lidar/Lifetime** - Sets the lifetime of scanned points (in seconds).  
  **Default:** `12`

- **Lidar/Range** - Sets the maximum scanning distance.   
  **Default:** `7000`

- **Lidar/PointSize** - Sets the size of each lidar point.  
  **Default:** `1`

- **Lidar/CullDistance** - Sets the minimal distance at which lidar points are no longer rendered  
  **Default:** `100`

- **ScreenUpdateDelay** - Sets the camera image refresh delay (in seconds).  
  **Default:** `0.03`

- **ScreenUpdateRadius** - Sets the distance from the player at which the screen updates.  
  **Default:** `7`

# Features:
## 360 Camera:
- Can rotate 360 degrees.
- Has three modes which control camera view rotation: **Up**, **Down**, and **Auto**.
- Modes can be changed by pressing **toggle** on the camera or by clicking the orange refresh button on the laptop while watching the camera.
- You can buy it in the in-game store under the **essentials** category for **200 points**.
- You can also craft it using a **good quality camera**, **plastic scrap**, and **electric scrap**.

## Lidar:
- Used to scan the surrounding environment.
- Displays detected objects as colored points, with different colors depending on object type.
- You can buy it in the in-game store under the **tools** category for **300 points**.
- Fully customizable through mod configs.

## CCTV mode:
- Can be enabled on any in-game TV.
- Has three different layouts to display multiple cameras: 1x1, 2x2, 3x3.
- You can enable CCTV mode by pressing **"Cameras"** button in the TV menu.
- To adjust CCTV system, you need to select a layout configuration, choose a cell for a camera, then select the camera.
